About PhotoSphere

PhotoSphere is a web-based photo gallery application developed as a B.Tech Web Designing Workshop mini project. It demonstrates HTML, CSS, JavaScript, responsive web design, browser file handling, form validation, and dynamic gallery management.

HTML5CSS3Vanilla JavaScriptFile APIlocalStorage

Project objectives

  • Build a semantic, responsive interface without a framework.
  • Practise arrays, objects, events, loops and DOM manipulation.
  • Handle real local files with validation and safe previews.
  • Prepare a clear path to a Spring Boot and MySQL backend.

Future Java backend

Demo mode active

The frontend is ready for a future Spring Boot REST API. Today, all gallery actions run locally in your browser.

GET/api/photosRetrieve gallery photos
POST/api/photosUpload image + metadata
GET/api/photos/{id}Retrieve photo details
DELETE/api/photos/{id}Delete an uploaded photo

One configuration point: API_BASE_URL in script.js. The future upload will use multipart/form-data.

No server is connected. Click the button to test the configured local Spring Boot URL.
